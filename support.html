Frequently asked questions

How are the exhibits numbered?

Three ways. Sequential numbers the exhibits in list order, as 1, 2, 3, A, B … Z, AA or I, II, III, with any prefix, suffix and starting value: PX-1, DEF-A. From File Names reads the number already in names like Ex. 65 Memo.pdf or Exhibit B - Contract.pdf. Trial Binder numbers by section: A-1, A-2, B-1; right-click an exhibit and choose Start New Section Here to begin the next letter.

To give one exhibit a number of its own, right-click it and choose Set Number….

Some rows are red and Export refuses to start

Every exhibit needs its own number. In From File Names mode a row turns red when its name carries no number, or when two files carry the same one. Rename the file, or right-click the row and choose Set Number….

A red row with a different reason is a file that cannot be used: unreadable, without pages, or restricted by its owner (see below). Remove it from the list to export the rest.

Sticker on the first page, or a slipsheet?

Both are in the Placement section. On the first page, the sticker goes in the corner you choose, at the margins you choose; drag it on the preview to move it for one exhibit only. A slipsheet is a separator page placed before each exhibit, the size of its first page, with a large sticker and, if you want, the exhibit's description. The exhibit's own pages are then left without a sticker.

Can the sticker be removed afterwards?

No, and that is the point. The sticker is drawn into the page itself as real text, not added as an annotation, so it cannot be deleted by accident or hidden by a viewer setting. To change a sticker, export again from the originals, which are never modified.

For the same reason, highlights, notes and filled form fields in the originals become part of the page: they stay visible but can no longer be edited. Web links keep working. Links that jump to another page of the same document are lost, and the summary at the end of the export says how many.

What about password-protected PDFs?

The app asks for the password before exporting, one file at a time, and you can skip any of them. Passwords are kept in memory only and are never written anywhere, not even in the project file. The stamped copy is written without the password: protect the output again if it has to be.

A PDF whose owner restricted printing, copying or editing is refused with a clear message on its row. Exhibit Stamp never removes those restrictions; ask for an unrestricted copy.

Bates numbers, bookmarks and the exhibit index

Turn on Bates Numbering to number every page, with prefix, digits, start number, position and font. The number runs continuously through all the exhibits, slipsheets included.

Export writes either one PDF with a bookmark for every exhibit, or one PDF per exhibit named from a pattern such as Exhibit {n} - {name}. An existing file is never replaced: a new name is chosen instead.

Export Index writes the exhibit list — number, description, pages and, with Bates on, the Bates range — as a Word document, a CSV spreadsheet or a PDF. Edit the descriptions right in the list before exporting.

The free version and Exhibit Stamp Pro

Every feature is in the free version, for jobs of up to 3 exhibits. Exhibit Stamp Pro is a one-time purchase that removes the limit. There is no subscription and no account.

Bought Pro on another Mac, or after reinstalling? Open the Exhibit Stamp Pro… window from the app menu and click Restore Purchases, signed in to the same Apple Account. Refunds are handled by Apple at reportaproblem.apple.com.

Can I save a job and come back to it?

Yes. File ▸ Save writes an .exhibitstamp project with the list, the numbers, the descriptions and every setting. Reopen it to change a description and export again. If an original has been moved or changed since, its row says so. Undo and redo cover every change in the window.

Should I check the exhibits before I file them?

Yes. Verify the output before filing or serving it. The app checks its own work — it re-reads every file it writes and refuses to keep one that failed that check — but the filing is yours to stand behind. Open the PDF, look at the stickers, and read the index against the exhibits.

Do you see any of my documents?

No. The app has no network access at all — see the privacy policy. Everything happens on your Mac.
